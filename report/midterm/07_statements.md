## Data and Code Availability

The PhysioNet “Gait in Parkinson’s Disease” database v1.0.0 [S7], [S8] is openly available under the Open Data Commons Attribution License v1.0. WearGait-PD [S9] is available under CC BY 4.0 through Synapse (syn52540892) after registration and acceptance of its data-use terms. The raw recordings of neither dataset are redistributed in our repository; its file data/raw/README.md gives the download steps (provisional for WearGait-PD until those data are downloaded), and every PhysioNet file we use matches the database’s published SHA-256 checksums. All code, results and figures are in the public repository https://github.com/Jsanson1/BMEN600_Group5. Its README lists the software (plain Python scripts; Python 3.11 or newer with NumPy, pandas, SciPy, scikit-learn, matplotlib and tabulate) and the script that produces each table and figure, and python scripts/run_all.py regenerates every output in this plan from the raw files.
