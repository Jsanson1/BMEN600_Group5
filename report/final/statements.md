## Data and Code Availability

The PhysioNet "Gait in Parkinson's Disease" database v1.0.0 [S7], [S8] is openly available under the Open Data Commons Attribution License v1.0. WearGait-PD [S9], [S20] is available under CC BY 4.0 through Synapse (syn52540892) to anyone with a Synapse account who accepts its terms of use. Neither dataset's recordings are redistributed in our repository; `data/raw/README.md` gives the download steps, the versions used (gaitpdb v1.0.0; WearGait-PD Version 1, Synapse folder syn55052683) and the checks of every file against its published checksum. The repository does hold derived tables with one row per participant: the dataset's study code, diagnosis, age, sex, sub-study or site, stride counts, the timing features and the models' predictions. They are shared under WearGait-PD's CC BY 4.0 licence, which allows the data to be shared and adapted with credit and a note of the changes [S20]. All code, results and figures are in the public repository https://github.com/Jsanson1/BMEN600_Group5. Its README lists the software (Python 3.11 or newer with NumPy, pandas, SciPy, scikit-learn, Matplotlib and tabulate, in `requirements.txt`), the script that produces each table and figure, and how to run them: `python scripts/run_all.py` regenerates every output in this paper from the raw files, and without WearGait-PD it runs the steps that need PhysioNet alone. The version corresponding to this submission is commit [to fill at submission].
